# F1 Race Pace Explorer

A React + TypeScript dashboard comparing F1 drivers' lap times and pit strategy.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## What to Build

Read **[REQUIREMENTS.md](./REQUIREMENTS.md)** — it has everything you need, including an F1 domain reference (no prior F1 knowledge required).
